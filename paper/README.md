# Research paper draft

Open this directory as an Overleaf project, or run `latexmk -pdf main.tex`
from `paper/` with IEEEtran installed. Confirm the author names and order,
write related work from the papers the team read, and add verified BibTeX
entries. Review the AI disclosure before submitting.

Use the dated [measurement plan](../docs/measurement_plan.md) for the
experimental protocol and the run manifests for the implementation and
execution details. Add the abstract and conclusion after checking the
results. The registration and timing tables are generated by the following commands from the
repository root.

```bash
python scripts/summarize_replay.py results/anvil/2026-11-20-full --out results/anvil/2026-11-20-full/summary
cp results/anvil/2026-11-20-full/summary/{registration_rows,timing_rows}.tex paper/
```

Regenerate the integrity and admission tables from both validation runs.

```bash
python scripts/summarize_validation.py results/anvil/2026-11-20-checks results/anvil/2026-11-20-checks-d3-128 --out paper
```

For the course hand-in, finish the draft for cross-team review and keep the
response to that review. Confirm the final author list, reproduce the
tables and figures from a clean checkout, and clear the final version and
venue with the instructor. Retain the submission record with the final PDF
and repository link.
